Install

Installed in four steps

Upload

In your dashboard, go to Plugins › Add New Plugin › Upload Plugin, choose the ZIP and click Install Now. Keep the file zipped.

Activate

Click Activate Plugin. There is nothing to set up: the plugin has no settings.

Back up

Take a full backup of your database with your host's tools or a backup plugin before your first replacement.

Open the tool

Find Search & Replace in the admin menu. Search first, then replace. See an example

Before you download

Is there a paid version?

No. Every feature is in the free plugin. It is licensed under the GPLv2 or later, so you may use it on as many sites as you like, including client sites.

Will it be in the WordPress.org plugin directory?

The plugin is prepared for the WordPress.org directory. Once it is listed there, you can also install it from Plugins › Add New Plugin by searching for "Scoped Search & Replace", and updates arrive in your dashboard. Until then, download the ZIP here; the changelog lists every version.

Does it send any data anywhere?

No. The plugin makes no outside requests, has no tracking and shows no ads. It only reads and writes your own database, on your command.

Should I use it on a live site?

Yes, with a backup taken first. If you have a staging copy, trying the replacement there first is even better.

How do I remove it?

Deactivate and delete it on the Plugins screen. It removes its own temporary data. Your content, including replacements you made, stays as it is.
