The scope

Five choices decide what can change

The search and the replacement each have the same five choices. Leave a choice wide, or narrow it down to one single page.

1. Search and count

A search that only reads

Enter a URL or any text and click "Search and Count". Nothing is written. You get the number of matching rows, the total number of times the text appears, and a table of every record.

  • Record ID, page or post ID, title, type and status
  • Meta key for custom fields, so you know which setting matched
  • Edit and View links that open in a new tab
  • Case-sensitive and exact: "Example.com" and "example.com" are different

2. Find and replace

A replacement that stays inside its lines

Enter the old and the new value with the same scope you searched. The plugin looks up the matching records again, re-reads each one just before changing it, and writes only those rows.

  • A confirmation with old value, new value, table, field and scope
  • Refuses empty values and an old value equal to the new one
  • Clears the WordPress cache of each changed post
  • Afterwards, a fresh search shows what is left in the scope

3. Results

A clear report after every run

The message says how many rows were updated and how many occurrences were replaced. Records that could not be changed, or were skipped because their data was damaged, are listed by ID so you can look at them.

The page you see after a search or replacement is a fresh page, so pressing reload in the browser does not send the form again.

Serialized data

Lengths that stay correct

Serialized values store the length of each piece of text. Change the text without the length and PHP can no longer read the value. The plugin unpacks the value, replaces the text at every level, and packs it again.

Plain SQL replace

a:1:{s:3:"url";s:22:"https://www.example.com";}

The text is now 23 characters long, but the value still says 22. PHP cannot read it, and the setting is lost.

Scoped Search & Replace

a:1:{s:3:"url";s:23:"https://www.example.com";}

Unserialized, replaced, serialized again: the length matches the text, and the setting keeps working.

Security

  • Only users with the manage_options capability (administrators)
  • A nonce on every request
  • Tables, fields, types and statuses checked against a fixed list
  • All values passed to the database through prepared queries

Light

  • Loads its files only on its own admin screen
  • Stores no settings; the last result is kept for 5 minutes, per user
  • No external requests, no tracking, no ads
  • Deleting the plugin removes its temporary data

Fits in

  • WordPress 5.8 or later, PHP 7.4 or later
  • Multisite: works on the site you are viewing
  • Every text can be translated
  • "Open tool" link right on the Plugins screen

What it never touches

Limited on purpose

Keeping the tool to posts and their custom fields is what makes every replacement predictable. These parts of your database are never searched or changed:

  • The options table: site address, widgets, theme and plugin settings
  • Users and user meta
  • Comments
  • Categories, tags and other terms
  • Custom tables created by other plugins

Your part

Always take a backup first

Replacements are written straight to the database and there is no undo button. The plugin reminds you on its screen and in the confirmation. Your host's backup, or any backup plugin, is enough.

Made a mistake? Replace the new value back with the old one, in the same scope. Or restore your backup.
