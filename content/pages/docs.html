1. Installing

  1. Download the plugin ZIP.
  2. In your dashboard, go to Plugins › Add New Plugin › Upload Plugin, choose the ZIP and click Install Now.
  3. Click Activate Plugin.
  4. Open Search & Replace in the left-hand admin menu, or click Open tool under the plugin's name on the Plugins screen.

Requirements: WordPress 5.8 or later and PHP 7.4 or later. The plugin has no settings page; everything happens on its one screen.

2. Choosing the scope

Both cards, Search and Count and Find and Replace, have the same box called Search Location and Content Scope. Its five choices decide which rows can be found and changed.

The tool starts on Post and Published. To work on pages, products or drafts, change the content type and status first. This is the most common reason for "no matches".

"All Content Types" removes the type filter completely, and "All statuses" removes the status filter. With both, every row of the table is in scope, including revisions, navigation menu items and reusable blocks. Use them when you really mean the whole site.

3. Search and count

Choose the scope, type a URL or any text in URL or Text to Search and click Search and Count. A search never changes anything. You get:

  • Matching Database Rows: how many records contain the text.
  • Total Occurrences: how many times it appears in all of them together.
  • A table with the record ID, page/post ID, title, type, status, meta key (for custom fields), the number of occurrences, and Edit and View links that open in a new tab.

Matching is exact and case-sensitive: Example.com and example.com are different, and so are http:// and https://. The count you see is exactly what a replacement with the same text and scope would change.

4. Find and replace

  1. In Find and Replace, set the same scope you used for the search.
  2. Enter Old URL or Text and New URL or Text. Both are required, and they must be different.
  3. Click Replace Selected Records. A confirmation shows the old value, new value, table, field and scope. Click OK only if all of it is right.

The plugin finds the matching records in the scope, reads each one again just before changing it, replaces every occurrence in it and saves it. Afterwards you see "Replacement completed. Updated n database row(s) and replaced n occurrence(s)." and a new search for the old value in the same scope, which normally finds nothing left.

Because the new value cannot be empty, the plugin cannot delete a piece of text entirely. Replace it with the text you want instead, or edit those few pages by hand using the Edit links from a search.

5. Custom fields and serialized data

Themes, page builders and plugins often save several settings in one custom field as a serialized value, a PHP format that records the length of every piece of text:

a:1:{s:3:"url";s:22:"http://old.example.com";}

If the text changes but the 22 does not, PHP can no longer read the value and the setting is lost. Scoped Search & Replace unserializes the value, replaces the text in every string inside it (also in nested arrays and objects), and serializes it again, so the lengths are correct.

  • A value whose serialized data is already damaged cannot be read safely. It is skipped, left exactly as it was, and its ID is listed under "Failed or skipped record IDs".
  • Objects of a class that is not loaded (for example from a deactivated plugin) are left unchanged.

6. Page builders

Most builders keep their layouts in custom fields. Choose wp_postmeta and Custom Field / Meta Value. The meta key column in the results shows which field matched.

  • Slashes written as \/. Some builders, Elementor among them, save layouts as JSON in which a URL looks like https:\/\/old.example.com\/shop\/. A search for https://old.example.com then finds nothing in post meta. Search for the part without slashes, such as old.example.com, and check the results before replacing.
  • Generated CSS. Some builders also write CSS files. After a replacement, regenerate them from the builder's own settings (in Elementor: Tools › Regenerate CSS & Data).
  • Caches. If a page still shows the old text, clear your caching plugin's or host's page cache.

7. What the plugin does not change

The plugin only works on the posts table (content, title, excerpt) and the post meta table (meta value). It never searches or changes:

  • the options table: the site address under Settings › General, classic widgets, Customizer and theme settings, plugin settings;
  • users and user meta, comments, categories, tags and other terms;
  • custom tables created by other plugins (for example form entries or SEO data);
  • files: images, theme files and builder CSS files.

When you move to a new domain, change the site address yourself under Settings › General (or with your host), then use the plugin for the content. Full guide

8. Backups and undo

Replacements are written straight to the database. The plugin keeps no copy of the old values, so there is no undo button. Always take a full database backup before replacing, with your host's backup tool or a backup plugin.

To reverse a replacement, run it again the other way round in the same scope: the new value as Old, the old value as New. This works when the new value did not already exist in those records before; otherwise restore your backup.

9. Who can use it

  • Only users with the manage_options capability see the menu and can run searches or replacements. By default that means administrators.
  • Every form is protected with a nonce, and the table, field, content type and status are checked against a fixed list before any query runs.
  • The result of the last action is kept for 5 minutes for the user who ran it, then deleted. After a search or replacement the page reloads as a normal page, so refreshing the browser never repeats a replacement.

11. Multisite and uninstalling

On a multisite network the tool works on the site whose dashboard you are in; each site is searched and changed separately.

To remove the plugin, deactivate and delete it on the Plugins screen. It deletes its own short-lived result data on every site. Your content, including all replacements you made, stays as it is.
