Your phone number changed, but only the Contact page should show the new one for now. Or a price on one landing page, a typo in a link on one product, a name that has to change in drafts but not in published posts yet. Most search and replace tools only offer "everywhere". Here is how to make a change in exactly one place.

For a handful of changes: the editor

If the text appears two or three times on one page, open the page in the editor and change it there. In the block editor, the Code editor (Options menu › Code editor) shows the whole page as text, so you can use the browser's find (Ctrl+F) to spot every occurrence.

That stops working when the text is hidden in a page builder layout or a custom field, appears many times, or is spread over several pages of one type.

With Scoped Search & Replace

The plugin lets you set the scope before you search or replace. To change the phone number only on the Contact page:

  1. Take a backup, then open Search & Replace in the admin menu.
  2. In Search and Count, choose the table wp_posts, field Post/Page Content, content type Page and status Published.
  3. Under Specific Page or Post, pick Contact. The list only offers pages that fit the type and status you chose.
  4. Search for the old number exactly as it is written, for example 020 7946 0000. You see how many times it appears on that page.
  5. In Find and Replace, set the same scope, enter the old and the new number, and confirm. Only the Contact page changes.

Other useful scopes

Tips for exact matches

  • Capitals count. The search is case-sensitive, so "Call Us" and "call us" are different texts.
  • The database holds HTML. Text that looks like Fish & Chips on the page may be stored as Fish &amp; Chips. If a search finds nothing, try a shorter part of the text without special characters.
  • Spaces and line breaks must match too. Searching for a shorter, distinctive piece (just the number, not "Phone: …") is more reliable.
  • Check the result. Use the View link in the results to open the page, and clear your page cache if the old text still shows.
